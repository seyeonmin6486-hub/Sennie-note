# 센니 노트 (Senni Note)

센니의 살림 · 레시피 · 최저가 기록을 한 곳에 모아 두는 개인용 모바일 웹앱(PWA).

- 사이트: https://seyeonmin6486-hub.github.io/senni-note/
- 아이폰 Safari에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 전체 화면으로 실행됩니다.

## 쓰는 법

- **검색**: 제목·내용·태그·카테고리까지 한 번에 찾습니다.
- **카테고리 탭**: 전체 / 🍳 요리·레시피 / 🧂 미용·건강 / 🏠 살림·쇼핑 / 📱 인스타·부업 / 📝 내 메모
- **세부 카테고리**: 카테고리를 고르면 아래에 세부 칩이 나타납니다.
  (요리 → 집밥·메인 · 집밥·간식 · 라면·분식 · 소스·시즈닝 · 디저트 · 보관법 / 미용·건강 → 바디·사우나 · 헤어 · 영양제 · 다이소·코덕 / 살림·쇼핑 → 쇼핑·비교 · 다이소·수납 · 다이소·생활 · 여행·쇼핑 · 여행·맛집 · 생활·꿀팁 · 병원·보험 / 인스타·부업 → AI 영상 제작 · 대본·프롬프트 · 숏폼 제작 · 인스타 수익화 · 스레드·제휴 · 편집 자동화 · 블로그)
- **📸 인스타 소재**: 릴스·카드뉴스로 쓸 만한 노트만 모아 봅니다. 노트를 열면 한 줄 훅을 확인·복사하고 [찜하기]로 표시할 수 있어요. 노트를 열면 한 줄 훅을 확인·복사하고 [찜하기]로 표시할 수 있어요.
- **+ 새 메모**: 폰에서 바로 추가합니다. 저장한 메모는 그 기기의 브라우저(localStorage)에만 저장됩니다.
- **상세 보기**: 표·체크리스트(체크 상태 저장), [전체 복사], 외부 구매 링크 버튼.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `assets/style.css` | 디자인 |
| `assets/app.js` | 검색·필터·상세·메모 저장 로직 |
| `assets/data.js` | **기본 내장 노트(31개) + 카테고리 정의** |
| `manifest.json` | PWA 설치 정보 |
| `sw.js` | 오프라인 캐시 |
| `icons/` | 앱 아이콘 (SVG / PNG 192·512·maskable·apple-touch) |

## 노트 추가하는 법 (AI·직접 편집)

`assets/data.js`의 `window.SENNI_NOTES` 배열에 항목을 하나 더 넣으면 됩니다.

```js
{
  id: 'n-example',            // 겹치지 않게
  cat: 'cooking',             // cooking | beauty | living | insta | memo
  sub: 'main',                // 카테고리별 subs id (선택)
  title: '제목',
  summary: '카드에 보일 한 줄 요약',
  tags: ['태그1', '태그2'],
  date: '2026-11-26',
  instaReady: true,
  instaHook: '인스타 릴스/카드뉴스 한 줄 훅',
  blocks: [
    { type: 'p', text: '문단 (<strong>굵게</strong>, <br> 가능)' },
    { type: 'h', text: '소제목' },
    { type: 'ul', items: ['목록'] },
    { type: 'ol', items: ['순서'] },
    { type: 'checklist', items: ['체크 항목'] },
    { type: 'table', head: ['재료', '분량'], rows: [['소금', '5큰술']] },
    { type: 'callout', tone: 'warn', icon: '⚠️', text: '주의사항' }
  ],
  links: [{ label: '구매 링크', url: 'https://...', note: '사이트 이름' }]
}
```

> 표·체크리스트·주의사항 블록은 그대로 상세 화면에 렌더링되고, [전체 복사]에도 반영됩니다.
